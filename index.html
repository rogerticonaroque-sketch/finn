FUNDAMENTOS

Introducción a la codificación

💻

¿Qué es la codificación?

La codificación es el proceso de transformar un algoritmo o solución lógica en instrucciones escritas mediante un lenguaje de programación.

Estas instrucciones permiten que una computadora pueda procesar datos, realizar operaciones, tomar decisiones y producir resultados.

⚙️

Proceso de desarrollo

Problema → Análisis → Algoritmo → Codificación → Compilación → Ejecución
02
CÓDIGO FUENTE

Almacenamiento y recuperación

¿Qué es el código fuente?

El código fuente es el conjunto de instrucciones escritas por el programador utilizando un lenguaje de programación.

El código debe almacenarse en un archivo para poder recuperarlo, modificarlo, compartirlo y ejecutarlo posteriormente.

Extensiones comunes

  • .c → Lenguaje C
  • .cpp → C++
  • .java → Java
  • .py → Python
  • .js → JavaScript
● ● ● programa.c

int main() {

    printf("Hola, mundo");

    return 0;
}

DECISIONES

Estructuras de selección

IF

Estructura if

Ejecuta un bloque de instrucciones solamente cuando una condición es verdadera. 

if (edad >= 18) {

    printf("Mayor de edad");

}
IF / ELSE

Estructura if-else

Permite seleccionar entre dos caminos posibles. 

if (nota >= 51) {

    printf("Aprobado");

} else {

    printf("Reprobado");

}
SWITCH

Selección múltiple

Permite seleccionar una alternativa entre varias opciones. 

switch(opcion) {

    case 1:
        printf("Suma");
        break;

    case 2:
        printf("Resta");
        break;

    default:
        printf("Inválido");
}
07
CICLOS

Estructuras de repetición

01

for

Se utiliza principalmente cuando conocemos el número de repeticiones. 

for (int i = 1; i <= 5; i++) {

    printf("%d\n", i);

}
Resultado: 1 · 2 · 3 · 4 · 5
02

while

Repite mientras una condición sea verdadera. 

int i = 1;

while (i <= 5) {

    printf("%d\n", i);
    i++;

}
La condición se evalúa primero.
03

do / while

Ejecuta el bloque al menos una vez y luego verifica la condición. 

int numero;

do {

    scanf("%d", &numero);

} while (numero <= 0);
Se ejecuta mínimo una vez.

Comparación de estructuras repetitivas

Estructura Evalúa Mínimo de ejecuciones Uso principal
for Antes 0 Número de repeticiones conocido
while Antes 0 Repetición condicionada
do/while Después 1 Menús y validaciones
08
CONTROL DE FLUJO

Sentencias break y continue

⛔

break

Interrumpe completamente el ciclo o estructura en la que se encuentra. 

for (int i = 1; i <= 10; i++) {

    if (i == 6) {
        break;
    }

    printf("%d ", i);
}
Resultado: 1 2 3 4 5
⏭️

continue

Omite la iteración actual y continúa con la siguiente repetición. 

for (int i = 1; i <= 10; i++) {

    if (i == 5) {
        continue;
    }

    printf("%d ", i);
}
Resultado: 1 2 3 4 6 7 8 9 10

💡 Recuerda

break termina el ciclo. continue solamente salta la iteración actual.

APLICACIÓN

Programa integrador

El siguiente programa combina variables, constantes, operadores, if-else, switch, for, do-while, break y continue.

● ● ● sistema_notas.c 
#include <stdio.h>

int main() {

    const int APROBACION = 51;

    int opcion;
    int nota;

    do {

        printf("\n===== SISTEMA DE NOTAS =====\n");

        printf("1. Registrar nota\n");
        printf("2. Mostrar números\n");
        printf("3. Salir\n");

        printf("Seleccione una opción: ");
        scanf("%d", &opcion);

        switch (opcion) {

            case 1:

                printf("Ingrese la nota: ");
                scanf("%d", &nota);

                if (nota >= APROBACION) {

                    printf("APROBADO\n");

                } else {

                    printf("REPROBADO\n");
                }

                break;


            case 2:

                for (int i = 1; i <= 5; i++) {

                    if (i == 3) {
                        continue;
                    }

                    printf("%d\n", i);
                }

                break;


            case 3:

                printf("Finalizando programa...\n");

                break;


            default:

                printf("Opción no válida.\n");
        }

    } while (opcion != 3);


    return 0;
}

🔎 Análisis del programa

const → constante int → tipo de dato if-else → decisión switch → selección múltiple for → repetición do-while → repetición break → interrupción continue → salto de iteración
